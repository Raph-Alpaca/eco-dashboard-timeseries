# 대시보드 사용 안내

## 열기
- 배포 주소: `https://raph-alpaca.github.io/eco-dashboard-timeseries/` (GitHub Pages) · 이전 판: `https://raph-alpaca.github.io/eco-dashboard/`
- 내 PC에서: 폴더의 `서버실행.bat`(또는 `run_server.bat`)을 더블클릭 → 브라우저가 열립니다. `index.html`을 직접 더블클릭하면 동작하지 않습니다(브라우저 보안 규칙).

## 화면 구성

| 탭 | 내용 |
|---|---|
| 개요 | 두 조사의 핵심 수치 8개와 바로가기 |
| 학교환경교육 현황조사 | 학생 · 교원 · 담당교원 · 학생·교원 비교. 상단 필터(학교급·학년·시도·권역·지역규모·성별/교원구분·근속)로 범위를 좁힙니다 |
| 환경교육 실태조사 | 전체 개요(두 해 참여 현황·공통 지표 히트맵[2024년/2025년/증감]·시도 타일맵) + 9종 기관유형 화면. 기관 화면은 **추이 2024→2025 / 2025년 / 2024년** 세 가지 보기 |
| 분석 | 문항 하나를 골라 행 축·열 축으로 교차표와 차트를 만듭니다 |
| 보고서 | 담은 패널을 모아 메모를 적고 PDF로 저장합니다 |
| 데이터 안내 | 수치의 출처·합성 방법·오류 보정·실데이터 교체 방법 |

## 실태조사 — 2024→2025 추이 보는 법
- 기관을 고른 뒤 위쪽의 **추이 2024→2025 / 2025년 / 2024년** 버튼으로 보기를 바꿉니다.
- **추이**는 두 해의 문항이 같은 것만 잇습니다. 값은 두 보고서에 인쇄된 공표값 그대로이고, 표에 두 해 값·증감·사례 수가 함께 나옵니다.
  - 문구만 조금 다른 문항은 카드에 `문구 다름` 표시와 두 해의 문항 문구가 함께 나옵니다.
  - 묻는 범위·분모·보기가 달라진 문항은 잇지 않고, 화면 아래 "잇지 않은 문항과 이유" 표에 이유를 적어 두었습니다.
  - 유아·초중등교육기관은 2024년(가중치 없음)과 2025년(가중 추정)의 산출 방식이 달라 학교급·기관구분별로만 잇습니다.
- **2024년**은 2024년 보고서의 표를 그대로 옮긴 값입니다(필터·교차분석 없음). **2025년**은 필터·패널 바꾸기·교차분석이 되는 기존 화면입니다.
- 조사 연도와 기준 시점은 한 해씩 다릅니다: 2024년 조사 = 2023년 말 기준, 2025년 조사 = 2024년 말 기준.
- 문항별 판정 전체는 '데이터 안내' 탭 맨 위의 **문항 대응표**에서 보고 CSV로 내려받을 수 있습니다.

## 패널(칸)의 버튼
- ⊞ **표 보기** — 차트 아래에 수치 표를 펼칩니다.
- ⚙ **지표 변경** — 조사 대상·문항·세부 항목·비교 축(2개까지)·값(비율/평균/긍정률)·차트 유형을 바꿉니다. 바뀐 구성은 브라우저에 저장됩니다. "기본 구성으로"를 누르면 처음 상태로 돌아갑니다.
- ⤓ **다운로드** — 표 CSV(엑셀에서 바로 열림), 차트 PNG(제목·출처 포함).
- ＋ **보고서에 담기** — 보고서 탭에 모입니다. 다시 누르면 뺍니다.
- ✕ **패널 제거**, **＋ 패널 추가**(화면 오른쪽 위)

## 보고서 만들기
1. 원하는 패널에서 ＋를 눌러 담습니다(여러 탭에서 담을 수 있고, 실태조사의 추이·2024년 카드도 담깁니다). **필터를 건 상태로 담으면 그 조건 그대로** 담깁니다.
2. '보고서' 탭에서 제목·부제·작성자·기준일을 적고, 항목 순서를 ↑↓로 조정합니다.
3. 각 그림 아래 메모를 적습니다(인쇄에 포함).
4. 'PDF로 저장(인쇄)' → 브라우저 인쇄 창에서 대상을 "PDF로 저장"으로 선택합니다. A4 세로, 그림마다 표가 함께 들어갑니다(표가 40행을 넘으면 앞 40행만 싣고 전체는 CSV로). 인쇄 창이 열리지 않으면 Chrome·Edge에서 주소를 열어 주세요(메신저 안의 브라우저는 인쇄를 지원하지 않는 경우가 있습니다).
5. '전체 CSV'는 담은 모든 패널의 수치를 한 파일(롱 포맷)로 내려받습니다.

## 읽을 때 주의
- 패널 아래 배지를 보세요. **`보고서 공표값`** 은 보고서에 인쇄된 값을 그대로 보여 주는 것이고, **`합성 데이터`** 는 보고서에 없는 조합(필터를 걸었거나 두 축을 교차한 경우, 공표되지 않은 축)을 공표값에 맞춘 합성 데이터로 계산한 것입니다. 공표되지 않은 축(학년·시도·성별 등)은 상위 집단과 같은 분포로 채워 차이가 없습니다.
- 실태조사의 추이·2024년 보기는 전부 보고서 공표값입니다.
- 사람 단위 조사에서 응답 30명 미만 집단은 `–`로 표시됩니다. 가중 추정에서 응답 10명 미만은 "불안정"으로 표시됩니다.
- 유아·초중등 실태조사의 n은 "응답 수(비가중)"와 "가중 N(모집단 추정)"을 함께 보여줍니다.

## 자주 쓰는 조작
- 시도별 지도: 패널 ⚙ → 비교 축 "시도" → 차트 "시도 타일맵".
- 학년별 추이: 비교 축 "학년" → 차트 "꺾은선".
- 두 축 교차(예: 학교급 × 성별): 분석 탭 또는 패널 ⚙에서 두 번째 축 선택.
- 화면을 처음 상태로: 각 탭의 "기본 구성으로", 필터는 "필터 초기화".
